# 🏃 Bengaluru Marathon 2026

> Run the city. Own your story.

An interactive, AI-powered marathon experience designed to bring together runners, live race information, route visualization, community engagement, and modern web experiences.

🔗 **Live Demo:** https://google-ai-bootcamp-rust.vercel.app/

🔗 **GitHub Repository:** https://github.com/MohammedFahad60/Google-AI-Bootcamp

---

## 📌 About the Project

**Bengaluru Marathon 2026** is a modern web platform created as part of the **Google for Developers – Build with AI Bootcamp**.

The project explores how modern web technologies and Generative AI can be combined to create an engaging digital experience for marathon participants and the wider running community.

The platform is designed around the idea of making a marathon more than just a race — giving runners access to useful information, interactive experiences, and a connected community.
