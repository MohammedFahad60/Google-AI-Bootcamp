# 🏃 Bengaluru Marathon 2026 — AI-Powered Web Experience

> **Built during the Google for Developers — Build with AI Bootcamp**

A modern, interactive marathon web experience built as part of the **Google for Developers Build with AI Bootcamp**. The project explores how Generative AI and modern web technologies can be combined to create an engaging digital platform around a real-world marathon experience.

🔗 **Live Demo:** https://google-ai-bootcamp-rust.vercel.app/  
🔗 **GitHub:** https://github.com/MohammedFahad60/Google-AI-Bootcamp

---

## 🚀 About the Project

This project was created during the **Google for Developers – Build with AI Bootcamp**, where the focus was on learning, experimenting, and building practical applications with AI.

The idea was to create a digital experience for the **Bengaluru Marathon 2026**, combining a modern user interface with AI-powered capabilities and interactive experiences.

Rather than treating AI as an isolated feature, the project explores how AI can become part of a broader user experience.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/MohammedFahad60/Google-AI-Bootcamp.git
```

### 2. Navigate to the project

```bash
cd Google-AI-Bootcamp
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### 4. Configure environment variables

Create a `.env` file based on `.env.example` and add the required API configuration.

> ⚠️ Never commit API keys or other sensitive credentials to GitHub.

### 5. Run the development server

```bash
npm run dev
```

Then open the local URL shown by Vite in your browser.
